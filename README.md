# 🚗 Dashboard de Análise de Veículos Usados

Este projeto consiste no desenvolvimento de um aplicativo web interativo desenvolvido com Streamlit para análise exploratória de dados de anúncios de veículos usados. A aplicação oferece visualizações como histogramas e gráficos de dispersão para apoiar a análise dos dados.

## 📊 Funcionalidades do aplicativo

O aplicativo permite:

- Visualizar uma tabela com os dados dos veículos
- Explorar a distribuição dos preços dos carros (histograma)
- Analisar a relação entre o ano do veículo e o preço (gráfico de dispersão)

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

## 🚀 Objetivo

Facilitar a visualização e compreensão dos dados por meio de gráficos e tabelas dinâmicas de forma interativa e simples.
